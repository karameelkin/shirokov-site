# Сайт для Кости Широкова: прототип

Кликабельный прототип одним файлом: `index.html` + `assets/`. Оплата, вход и закрытые видео в нём ненастоящие.
Режим «Гость / Спонсор / Папик» переключается внизу справа.

Запуск: `python3 -m http.server 8791` в этой папке, затем открыть http://127.0.0.1:8791/
